# Beginner Learning Roadmap

Do not start by coding everything.

Step 1: Understand C and D.
Step 2: Learn to read a payoff matrix.
Step 3: Find a dominant strategy.
Step 4: Find Nash equilibrium.
Step 5: Understand Pareto optimal/inferior.
Step 6: Learn repeated games.
Step 7: Learn Tit-for-Tat.
Step 8: Design the human experiment.
Step 9: Code the simple game.
Step 10: Add strategies.
Step 11: Run the tournament.
Step 12: Make graphs.
Step 13: Write results and discussion.

Checkpoint:
Before coding, you should be able to explain why (D,D) is a Nash equilibrium and why it is Pareto-inferior to (C,C).

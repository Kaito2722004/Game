# Prisoner's Dilemma Strategy Tournament
## Project Overview

Goal:
Study Prisoner's Dilemma using theory, a human classroom experiment, and an Axelrod-style computer tournament.

Main research questions:
1. Does the Nash equilibrium prediction of mutual defection match human behavior?
2. How does repeated interaction affect cooperation?
3. Which strategy performs best in an iterated Prisoner's Dilemma tournament?
4. Does trust/expectation of cooperation relate to actual cooperation?

Core payoff matrix:
| | B: Cooperate | B: Defect |
|---|---:|---:|
| A: Cooperate | (3,3) | (0,5) |
| A: Defect | (5,0) | (1,1) |

Notation:
T=5, R=3, P/U=1, S=0.
Conditions: T > R > P(U) > S and R > (S+T)/2.
